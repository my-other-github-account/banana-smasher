## Release rule

Performance is part of product correctness. A pack is not releasable until the exact same final model directory, wheel pair, image digest, serve arguments, and cache state pass every required API, decode, concurrency, and prefill cell below.

Results from another artifact, basis, repair update, image, instrument, or workload cannot fill a missing cell.

Every result row must include:

- source commit;

- pack-manifest SHA-256;
- base-index SHA-256;
- assignment SHA-256;
- repair-manifest SHA-256;
- repair-checkpoint SHA-256 and update;
- served model name;
- hardware architecture;
- exact argv/runtime-defaults SHA-256;
- instrument revision;
- prompt/decode lengths;
- concurrency;
- sample count;
- temperature and seed policy;
- warm/cold state;
- measured status and failure reason.

## Warmup protocol

Before timing, warm the complete 15-cell shape matrix:

| Prompt tokens | C1 | C2 | C4 | C8 | C16 |
|---:|:---:|:---:|:---:|:---:|:---:|
| 32 | required | required | required | required | required |
| 512 | required | required | required | required | required |
| 8192 | required | required | required | required | required |

Warmup must prove the graph and kernel dispatch used by every cell. Warming only C1 or only one prompt length is insufficient.

Timing begins after the complete matrix is ready. A cache or graph generated by a different model artifact does not count as warmup.

## Measurement discipline

- Same instrument for all compared rows.
- Minimum `n=5` timed repetitions per accepted row.
- Temperature `0.2` where sampling is part of the workload.
- Freeze prompts, tokenization, stop conditions, maximum output tokens, scheduler configuration, and cache policy before the run.
- Report request throughput and aggregate generated-token throughput for concurrency rows; do not mix them.
- Report prefill tokens/s separately from decode tokens/s.
- Report mean, median, standard deviation, minimum, maximum, and all individual samples.
- Any error, empty completion, early termination, timeout, or fallback censors the row and blocks acceptance until rerun.
- Use the same-work rule for speed comparisons.

## Required dispatch evidence

### Decode

- `mblock=4` compact routing geometry;
- scalar path for `valid_m < 4`;
- vector-M4 path for `valid_m == 4`;
- C8/C16 full compact expert blocks visibly use the vector-M4 path;
- capture sizes 1, 2, 4, 8, and 16 are active;
- no direct Python CUDA dispatch or generic slow fallback is accepted.

### Prefill

- `mblock=16` prefill geometry;
- admitted `mc4` path for full tiles;
- fragment-major `mc4afrag` path where its exact assets are required and present;
- exact fallback policy is reported; a missing required release accelerator is fatal.
